# Carina — план

Лёгкий десктоп-аудиоплеер со стеклянным виджетом на рабочем столе и встроенным проводником музыки.
Исследование: `<project-dir>` (BRIEF/REVIEW P01, P02) и `answers/P0*_*.md`.

## Решения
- 22.10.2026 — название Carina (запасное Nebulon). Стек: Tauri 2 + Rust + Svelte. Сначала Windows, потом macOS;
  на Linux только плеер, без виджета.
- 22.10.2026 — **две версии: бесплатная (уже крутая) и платная Pro.** Раскладку функций решаем после ответа Gemini P02 §5.
- Продвижение (мессенджеры, площадки, запуск) — часть проекта, план по ответу Gemini P02.
- Лицензия кода — не выбрана (GPL-3.0 / source-available / MIT).

## Этапы
1. **Прототип виджета (Windows)** — стекло, правый нижний угол, переживает Win+D, кнопки нажимаются,
   показывает трек, который сейчас играет в системе (Spotify, браузер, любой плеер).
2. Аудиодвижок: symphonia + cpal, gapless, медиаклавиши (souvlaki).
3. Проводник музыки: дерево папок, теги и обложки (lofty), поиск.
4. Free/Pro, подпись, Microsoft Store, запуск.

## Виджет — 22.10.2026, вечер

## Переключение треков — 22.10.2026
- «Не переключает» = плеер сам запрещает: Windows Media Player с одним открытым файлом даёт next=false, prev=false
  (диагностика: `cargo run --release --example sessions`). Виджет гасит недоступную «вперёд» с подсказкой,
  «назад» без предыдущего трека начинает текущий сначала. Полное решение — свой движок Carina (играет папку подряд).

## Полноценный плеер — 23.10.2026, ночь
- Проверка движка без звука: `cargo run --release --example check -- <папка>` — все форматы (mp3, flac до 96к/24,
  m4a/aac, ogg, wav, aiff) и 51 реальный mp3 из Desktop\Aggressive_Trap_17_Legends — 0 ошибок.

- Кэш тегов (tags.json в кэше) — папки и поиск не перечитывают теги.
- Медиаклавиши и системное окно громкости Windows (своя SMTC), трей (показать/спрятать, автозапуск, выход),

- Открытие из Проводника / повторный запуск / перетаскивание файлов: один файл → вся его папка с этого трека.
  Ассоциации файлов — в установщике. Проверено без кликов (sessions example).
- Пустая системная сессия самой Carina не читается («device not ready») — пропускаем её и свою сессию при показе
  чужих плееров.

## Ошибки (не повторять)
- 22.10: тест кнопок на реальных плеерах пользователя — пауза/запуск чужой музыки. Тестировать на своём тестовом
  плеере или без кликов по медиа-кнопкам; предупреждать заранее.
- 22.10: UI-тест кликами, когда пользователь вернулся к компьютеру (на экране было его видео) — клики могли попасть
  в его окно. Перед каждой серией кликов проверять, что на переднем плане рабочий стол; иначе не кликать.
- 22.10: `cargo build` без tauri CLI собирает exe с адресом dev-сервера (белый экран) — собирать только `npx tauri build`.
